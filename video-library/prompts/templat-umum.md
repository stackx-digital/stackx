# Templat umum

## Untuk Claude / Claude Code

```
Hasilkan video animasi [30] saat, saiz [POTRET 1080x1920 (9:16) / LANDSKAP 1920x1080 (16:9)],
30fps, MP4 dengan audio. Gaya: [nama gaya, atau tampal prompt gaya dari folder prompts/].

BAHAN
- Gunakan gambar yang saya lampirkan: [senarai gambar & kegunaan].
- Buang logo/teks/jalur dari gambar asal jika ada.

STRUKTUR CERITA
1. Pembuka (0–3s): soalan atau ayat pendek yang menarik perhatian.
2. Pengenalan (3–6s): foto utama + nama/tajuk.
3. Babak utama: [4–5] babak, setiap satu 3–5 saat (tahun/angka, satu perkataan besar, tiga perkataan bersiri).
4. Klimaks: momen paling penting.
5. Penutup: foto akhir + slogan + [nama / logo / laman web], pudar ke hitam.

TEKS (bahasa: [Melayu / Inggeris])
[fakta / garis masa / poin utama]

MUZIK (cipta sendiri, bebas hak cipta)
[gaya muzik, BPM, mood]. Mula perlahan, hentakan selepas pembuka, riser sebelum klimaks, pengakhiran lembut.

Nada: [neutral & faktual / inspirasi / promosi].
Tunjukkan frame pratonton sebelum render penuh.
```

## Untuk penjana video AI (Veo, Kling, Runway, Sora)

```
[Vertical 9:16 / Horizontal 16:9] cinematic video, [duration] seconds, [style] style.
[Background] featuring [subject description], slow cinematic [push-in / push-out / pan] camera movement.
Large bold [colour] sans-serif typography appears one word at a time with a blur-to-sharp reveal.
Mood: [inspiring / emotional / calm]. Ending: [final shot], gentle fade to black.
Music: [description].
```

Tip: guna image-to-video untuk wajah/produk sebenar; tambah teks sendiri dalam CapCut; jana klip 5–10s setiap babak lalu cantum.
